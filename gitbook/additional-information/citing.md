# Citing COMPAS Masonry

COMPAS Masonry is freely available under the MIT License. If you use COMPAS Masonry for any projects, publications or other applications, please cite:

```bibtex
@misc{compas-masonry,
    title  = {{COMPAS Masonry}},
    author = {},
    year   = {},
    doi    = {10.5281/zenodo.},
    url    = {https://github.com/BlockResearchGroup/compas-Masonry},
}
```
